# Security

## Found a security problem?
For example: a way this tool could leak someone's key or someone else's data.

Please report it **privately**: on this repo, open the **Security** tab and click **Report a vulnerability**.
Don't post details publicly, and **never include your key (token)** in any report, public or private.

## Fixes
Only the latest release gets fixes. Always download from the
[latest release](https://github.com/lookitsevan/threads-reply-archiver/releases/latest).
